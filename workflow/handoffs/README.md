# Agent Handoffs

Store actual task handoffs here. Dated architect, developer, and reviewer records
track executed work; human verification remains pending unless explicitly recorded.

For each handoff record: task ID, actor/agent role, input commit and spec revision,
requirement IDs, permitted scope, changes, commands and results, findings,
unresolved questions, and human verification status. Do not invent approvals or
include credentials, private notes, or hidden reasoning.

Record human approvals concisely using status, date and accepted scope. Do not name
the approver or quote chat messages. For example: `Human acceptance: Approved on
21 October 2026; scope: lifecycle increment.` This formatting rule does not supply
approval; record it only after an actual authorized human decision.

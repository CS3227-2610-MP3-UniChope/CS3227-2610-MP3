# Development Interaction Summaries

Store AI-generated summaries of development prompts and interactions here. A human
must verify each summary's accuracy before treating it as evidence. Track coverage
across team members/sessions; a single planning summary does not cover all work.

Suggested filename: `YYYY-MM-DD-contributor-topic.md`.
Record contributor, date/session scope, requests, decisions, changed files,
commands/results, unresolved issues, and human verification status. Exclude keys,
passwords, private consultation notes, and hidden reasoning. Distinguish proposed
work from completed work and fake-provider checks from real-provider evaluations.
